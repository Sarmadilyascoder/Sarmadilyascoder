### Featured Product

## SiAutomate — Customer Follow-up Tracker

**SiAutomate** is a secure customer follow-up CRM for small businesses. It gives teams one shared place to manage leads, record customer context, schedule next actions, and avoid missed follow-ups.

| Area | What it provides |
| --- | --- |
| Lead management | Customer records, pipeline status, ownership, search, filters, and CSV import/export. |
| Follow-up workflow | Exact-time reminders, snoozing, rescheduling, completion tracking, and a shared activity timeline. |
| Team operations | Organization workspaces, role-aware access, teammate invitations, and workspace isolation. |
| Reliability | In-app alerts, transactional email support, retry handling, automated tests, and live deployment checks. |

The product is built with **TypeScript, React, Node.js, Express, tRPC, Drizzle ORM, and MySQL**.
